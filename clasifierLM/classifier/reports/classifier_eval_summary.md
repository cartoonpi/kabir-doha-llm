**v2 (100 themes + none, 100 images; d=100, B=16384, 6.6 MB).** On the synthetic test set (2,769 requests, ~25 per theme) the fastText-style model gets top-1 0.783, top-3 0.899, top-5 0.927, and 0.818 family-level accuracy, about level with logistic regression (top-1 0.780, macro-F1 0.795) and far ahead of keywords (0.322). Images are the model's weak side compared with logreg (micro-F1 0.913 vs 0.980): detecting an image word is close to keyword spotting, and the shared 100-number vector has to serve 101 themes as well.

**The human-set numbers are not meaningful yet.** The 56 requests were labelled with the v1 10-theme vocabulary, so a correct, more specific v2 answer (e.g. "people bowing to idols" → `pratima`) counts as wrong, and newly added images (moon, ocean, temple) count as false alarms. The owner is relabelling and extending the set.

**Shortcuts found and fixed during v2:** writer-specific openers ("doha pls" 95% one family) → frame stripping; poem words ("poem" → none 89%) → poem-word randomization. **Still open:** everyday-object "none" topics make some objects a mild none cue ("lamp" 2.2× base rate); "lines" (122 rows) still leans none; most top confusions on test are X → none, set by the calibrated t_theme = 0.35; everyday grief phrasing ("losing someone dear") is rare in training. **Next:** the relabelled + extended human set, then reconsider t_theme on it and rebalance the object-none topics.
